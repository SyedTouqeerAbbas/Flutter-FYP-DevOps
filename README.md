# Flutter FYP DevOps Automation

## Introduction
This project demonstrates DevOps automation using GitHub Actions with a Flutter Final Year Project.

## Technologies Used
- Flutter
- Dart
- GitHub Actions
- CI/CD

## Objective
The objective of this project is to automate workflow execution using GitHub Actions.

## Workflow
The workflow automatically runs whenever code is pushed to the GitHub repository.

## Features
- Automated workflow execution
- Continuous Integration
- GitHub Actions automation

## Conclusion
GitHub Actions improves software development efficiency through automation and CI/CD practices.
